利用条件

ひとことで言えば、Beltkeepはジャーナルです。コーチングでも医療上のアドバイスでもなく、あなたがどう練習し、どう戦うかについての約束でもありません。

Beltkeepとは

Beltkeepは、あなたのブラジリアン柔術のトレーニングを記録します。記録した練習、メモとテクニック、帯、目標、そしてそこから生まれるグラフです。入力された内容を示すだけで、評価はしません。

コーチングでも医療上のアドバイスでもありません

Beltkeepはコーチでも医師でも医療機器でもありません。格闘技にはけがのリスクがあります。無理のない範囲で練習し、自分の体とコーチの声に耳を傾け、不安があるときは専門家に相談してください。数字やグラフは入力された内容の記録であり、助言でも約束でもありません。

独立したアプリ

Beltkeepは、いかなる連盟、ブランド、道場とも提携しておらず、公認も受けていません。帯やテクニックの名称は、この競技で一般的に使われる言葉です。

購入

Beltkeepに無料プランはありません。年間・月間のどちらのプランも、新規の登録者には7日間の無料トライアルが付きます。トライアル終了の24時間前までに解約しない場合、最初の期間の料金がAppleアカウントに請求されます。その後、サブスクリプションはAppleアカウントの設定で解約するまで、毎年または毎月自動的に更新され、支払い済みの期間の終わりまで利用できます。プランが終了しても何も削除されず、ジャーナルを書き出せます。支払いはAppleが処理し、RevenueCatには購入が通知されます（プライバシーポリシーをご覧ください）。返金はAppleの規則に従ってAppleが処理します。購入を復元で、同じAppleアカウントの別のデバイスにプランを戻せます。Appleの標準使用許諾契約（Licensed Application End User License Agreement）がこのアプリに適用されます。

あなたのデータ

記録はお使いのデバイスに保存され、あなたのものです。サーバーにコピーはないため、バックアップのないまま端末を失うとデータも失われます。バックアップフォルダを設定して維持してください：設定 → バックアップと書き出し。
